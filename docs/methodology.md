# Methodology

The planned DTI workflow is: drug input -> molecular representation -> feature generation -> target representation -> model inference -> evaluation and interpretation.

Phase 1 only establishes the study composer and pipeline contract. Future work must document the dataset source and license, positive/negative interaction definition, split strategy, leakage controls, random seeds, and model version alongside every prediction.

A probability from a model is a computational estimate. It is not experimental confirmation and must be presented with model, dataset, and uncertainty context.
